# Native grocery reminder navigation

This bounded fictional acceptance slice fixes reminder exits in the five native reminder editors. The Grocery editor previously exposed a 36pt-high Back target, and its unsaved-choice confirmation popover omitted the cancel choice. Each editor now uses the existing 44pt Quiet toolbar button and a native alert with explicit **Keep editing** and **Discard choices** actions. Existing cancellation, reload and busy-state behavior is preserved.

Actual interaction scope is the existing unchecked **QA rice**, 100g, grocery `d24cc35d-a6ae-44c6-9780-e28f8723d44d` in fictional household `be772ffd-3ab5-41d5-8438-647a79a553da`. Alex's owned SE3 simulator performed navigation and unsent local choices. Alex and Sam used the normal authenticated reminder-context API to read this exact item. No Save, Retry, Remove, grocery completion, hosted mutation, reminder worker, push permission or production operation was performed. Shipping Chore, Meal, Renewal and Recurring editors received the same narrow source change and compiled; their actual navigation was not exercised here.
