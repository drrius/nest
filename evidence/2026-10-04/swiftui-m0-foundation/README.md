The newly created clean simulator is explicitly recorded and shut down. No account, imported data, Apple authentication or permission selection is added to it. The original authenticated simulator's data/Keychain remain; it returns to Today. All artifacts are exported by explicit allowlist with credential/JWT scans.

M0's exit says a real executable test route must exist with recorded identity and explicit environment limits. It explicitly allows simulator-only checks while permission/calendar/push remain separate physical gates. Those foundation criteria are now demonstrated. Requiring both-phone acceptance to leave M0 would move M3/M6/M8/M9 requirements into this gate.

The maximum-text sign-in screenshot reveals clipped copy in build16; this is an M1 accessibility finding, not a claim of satisfactory design. A subsequent native scrolling/clipping fix is verified separately and is newer than the available beta. Owner design acceptance, live AI, both-member physical sign-in/offline/calendar/push and migration/release acceptance remain open.
