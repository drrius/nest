# Native PDF picker cancellation

The manually selected `NestAccessibility` scheme runs against the authorized
nest-test member session on the owned iPhone SE3/iOS26.3 simulator. It opens Money's
real expense form and Apple's document picker, browses On My iPhone and the single
owned synthetic fixture folder, and identifies the sole640-byte PDF. It returns
to On My iPhone and presses the rendered X at its audited SE3 position. It requires
the picker/file/Cancel element to disappear and Choose PDF to become hittable,
then verifies no attachment, pending upload, removal control or receipt error.
It returns to the expense form without
an attachment, pending upload, removal control or receipt error. The final source
also returns to Today and verifies the native tab's selected state.

Earlier attempts failed on observer assumptions: two Browse elements, a folder
label instead of its collection cell, a hidden filename extension, and Apple's
Cancel element having the `Other` role and `isHittable == false`. Failed result
bundles are retained on the Mac. A subsequent cleanup assertion incorrectly
required a Today section and then a selected tab while the picker still covered
Nest. The old Cancel accessibility frame actually overlapped the native More
button; querying the underlying form's existence falsely passed. That run is
superseded by the strict picker-gone/form-hittable check. Folder navigation also
hid the rendered X; returning to root browsing exposes it. The physical control
check is explicitly restricted to the owned375×667/iOS26.3 fixture. It does not suppress
accessibility findings or claim that Apple's Cancel control passes a semantic,
contrast or touch-size audit.

The PDF is an audited synthetic one-page text fixture, with no financial record,
script, encryption or embedded form. Its local Files copy lives only in the
owned simulator folder `Nest Receipt QA 20261005`; no existing Files content was
changed. Test source belongs only to the manually selected UI test target.

Signed preparation gates verify the stable nest-test API/Supabase origins and
disabled push. Native compiled app/UI-test/project inputs are compared with Linux
source. All64 scoped command slots are empty before and after the run; large/light
settings and the existing Keychain/session are preserved. The separate final
verification records the final test outcome and restoration checks.

all61 financial events and complete allocation/ledger/Storage metadata match.

the separate schedule-fix check again finds identical finance/Storage fingerprints.
