# Nest artwork

`icon.png` was generated with the built-in image-generation tool on 19 September 2026 for this app. It is an opaque square PNG depicting two seeds in a restrained green nest on a warm neutral background. No legacy artwork was copied. Expo can resample the square source for native icon sizes during prebuild.

Prompt direction: minimal abstract nest, two seeds, Quiet olive/dark green and warm off-white, no text, no device mockup, no rounded icon frame. Functional interface icons use SF Symbols instead of generated artwork.
