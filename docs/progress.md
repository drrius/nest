## PR #15 review corrections

Independent review found that a later network failure could clear a prior authorization denial, and warm foreground revalidation unmounted the loaded chore screen offline. Denial now stays blocked until successful authorized work. Same-actor warm revalidation retains only the previously verified in-memory identity during transient failures; logout, actor changes and definitive denial clear it. Added direct verifier/subscription and controller regressions. Self-review also added an expected-household header checked against verified API membership plus household-bound response envelopes, preventing a same-actor household change from contaminating another cache. All corrections passed exact-head independent rereview and CI before merge.

Rereview also found transient credential refresh failures incorrectly mapped to session loss. The credential adapter now separates retryable refresh/storage availability from confirmed missing/rejected credentials. Two adapter-to-controller regressions prove warm offline enqueue and sticky confirmed loss; all 15 chore tests pass locally.
