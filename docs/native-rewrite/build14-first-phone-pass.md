Nest0.1.0/build14 is valid and internally available in TestFlight. Partner tester access is still unverified. Availability evidence (historical artifact removed) records the supported Apple read. This is the separate nest-test environment, with fictional test entries. Household OS production is unchanged.

Before updating, reconnect your existing Nest installation and let pending grocery/chore checks synchronize. If unresolved changes remain, report the message before updating. Do not delete the app to clear them.

1. In TestFlight, update Nest and confirm **0.1.0 (14)**. Sign in with your existing Apple account and check that Profile identifies you correctly. Report any sign-in error rather than creating another account.
2. Open **Today, Meals, Calendar and Money**, then open the assistant and Profile and return. Check light/dark appearance and your preferred text size. Send a screenshot of any layout that feels wrong, with the tab and build number.
3. In **Money → Expense**, enter a clearly named test expense for **CHF1.01** and review the amount/split with the keyboard open. Return through Edit and check the draft remains. Stop before Save for this first UI pass. This does not verify financial posting.
4. On Calendar, check the date picker and permission explanation. Sharing starts off. You can decline access; the other tabs must still work. Personal-calendar/busy-sharing acceptance needs the separate two-phone checks.

AI generation and notification delivery remain disabled. Empty retained recurring lists do not prove migration workflows. This first pass checks installation, identity and usability; it does not close financial, offline, meal-generation, calendar-privacy, accessibility or migration acceptance.
