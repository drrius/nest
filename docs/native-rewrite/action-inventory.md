# First-release action inventory

The table records the approved action vocabulary, not literal API/tool names or acceptance status. The current source map below connects implemented action families to native surfaces, registered tools and verification sources. File existence and tool registration do not establish end-to-end acceptance. No arbitrary RPC/table access is exposed to models.

Every server command derives member/household from verified bearer identity and current membership. Private means owner-only even between partners. Mutation retries reuse operation identity; version checks prevent overwrites. Read caches exclude credentials and private chats. An AI handoff must describe navigation only; it cannot claim the underlying device action completed.

Pure presentation operations (tab switch, filter, week navigation, opening a form, canceling an unsaved draft) do not mutate household state. AI can return an authorized deep link or device handoff for these. Permission denial must leave independent product areas usable. Every mutation above needs failure/recovery handling before its surface is complete.

## Audit interpretation and remaining acceptance

- Reserved `profile.update` does not add an unapproved profile editor; the confirmed scope is existing Apple identity plus the implemented preferences. `recipes.remove` maps to archival, preserving planned-meal history. Chore acceptance maps to `respondChoreTransfer` with the explicit recipient decision.
- Handoff completion means only that a navigation card was produced. It never means OS permission, enrollment, sign-out, file selection/upload, meal approval, ingredient addition or financial posting occurred. Inspect [SwiftUI result routing](../../apps/ios/Nest/Assistant/AssistantHistoryScreen.swift) and the typed `Assistant*Link` parsers in [Nest Core](../../apps/ios/Nest/Core). Saved-recipe create/edit/archive results now bind typed receipts and refresh native library/detail through [recipe destinations](../../apps/ios/Nest/Assistant/AssistantRecipeDestination.swift); controlled simulator links have bounded evidence, and ordinary meal place/saved-place/replace/remove/move/leftover results now bind [canonical typed receipts](../../apps/ios/Nest/Core/AssistantMealActionLink.swift) to fresh planned-meal reads with [controlled native evidence](../../evidence/2026-10-01/swiftui-assistant-meal-links/README.md). Grocery add/edit/remove/check results now open a fresh authorized read-only current-item destination; receipts themselves lack actor/household fields, so authorized transcript provenance and fresh reads provide scope. Routine create/edit/pause/resume/archive results now bind scoped receipts and open fresh current chore controls. Both slices have [local wire/HTTP evidence](../../evidence/2026-10-01/swiftui-assistant-grocery-links/README.md) and [routine evidence](../../evidence/2026-10-01/swiftui-assistant-routine-links/README.md), with native model/parsing CI passing at source663c3aca and owned rendered navigation pending. Completion/skip/reschedule/handover receipts now link to existing current authorized work and handover screens, preserving recorded completer/date and distinguishing historical requests from acceptance. [Chore evidence](../../evidence/2026-10-01/swiftui-assistant-chore-links/README.md) records passing source d3d6918a native CI; owned rendered navigation remains unverified. Live model selection and complete result navigation remain unverified. Food/cooking/notification-save and private-memory-removal receipts now bind exact own-account typed commands and link to existing authorized readers; [settings evidence](../../evidence/2026-10-01/swiftui-assistant-preference-links/README.md) records current-source native CI. Generic notices cannot regain grocery success after a rejected canonical binding, with [regression evidence](../../evidence/2026-10-01/swiftui-assistant-result-fallback/README.md). Owned rendered settings navigation and live provider remain unverified. Retained TypeScript fixtures do not prove SwiftUI behavior.
- Ordinary requested household writes, explicit financial/meal/memory approvals and device-only actions remain distinct. The registry has no generic SQL/RPC tool and no financial decision/execute tool. Scheduled fixed posting is implemented separately and remains inactive in hosted environments.
- This source audit does not certify every interaction or integration. Required remaining proofs include live streaming and structured generation, both-member native journeys, Apple identity/Keychain, EventKit privacy, receipt Storage bytes, APNs, accessibility, release binary and full migration reconciliation.
- Previous dated implementation notes are retained at `b6a1a937e4ca65740f995f986163b0cd7984b835:docs/native-rewrite/action-inventory.md`. Their statements about unfinished slices or pending CI are historical, not the current state.
