# First-release action inventory

This is the approved implementation contract, not a claim of working tools. All rows are **planned** until linked to actual command, UI, tool/handoff and test files. Command names below reserve a finite vocabulary; no arbitrary RPC/table access is exposed to models.

Every server command derives member/household from verified bearer identity and current membership. Private means owner-only even between partners. Mutation retries reuse operation identity; version checks prevent overwrites. Read caches exclude credentials and private chats. An AI handoff reports completion only after device acknowledgment.

Pure presentation operations (tab switch, filter, week navigation, opening a form, canceling an unsaved draft) do not mutate household state. AI can return an authorized deep link or device handoff for these. Permission denial must leave independent product areas usable. Every mutation above needs failure/recovery handling before its surface is complete.
