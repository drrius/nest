# Build15: first phone pass

Nest0.1.0/build15 is valid and internally available in TestFlight. Availability evidence (historical artifact removed) records the supported Apple read. Partner access and actual installation are still unverified. This uses the separate nest-test environment; Household OS production stays unchanged.

Before updating, reconnect the installed app and let pending grocery/chore checks synchronize. Report unresolved changes; do not delete the app to clear them.

1. Update in TestFlight and check **0.1.0(15)**. Sign in with your existing Apple account; Profile must identify you correctly.
2. Open Today, Meals, Calendar and Money, then Ask and Profile and return. Check your preferred text size and light/dark appearance. Send screenshots of confusing or clipped layouts with the build number.
3. In Money→Expense, enter a clearly named **CHF1.01** test draft. With the keyboard open, use Review, check the split, return through Edit, and verify the fields remain. Stop before Save for this first pass.
4. In Money→Financial history, open an existing entry and return. If Load older entries appears, load them, open an older entry, and return; the loaded entries should remain.
5. In Today→Groceries, inspect add/edit forms and Cancel. Checking an existing item must never record an expense. Real two-phone offline/retry checks remain in the full checklist.
6. If a handover is present, open its review and Cancel; the selected chore/action must be clear and responsibility unchanged. Skip this step if none is present.

Live AI, scheduled bill posting/reminders, and push delivery remain disabled while provider/worker setup is incomplete. Basic installation/UI checks do not establish financial, offline, meal-generation, calendar-privacy, accessibility or migration acceptance. Both partners still need the [full phone checklist](swiftui-phone-acceptance.md).
