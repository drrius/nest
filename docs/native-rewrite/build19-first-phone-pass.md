# Build19 first phone pass

Update Nest to0.1.0/build19 in TestFlight. Reconnect and synchronize pending chore/grocery changes before updating; keep unresolved changes intact. This beta uses nest-test, not Household OS production.

Open Today, Meals, Calendar and Money. Check the common header, side margins and Profile/Ask placement in your usual appearance and text size, then dark mode and your preferred larger text size.

In Meals, open Saved meals and New recipe. Cancel without editing: it should close directly. Reopen, enter zero servings and cancel: Keep editing should preserve the input; explicit Discard should close. The keyboard checkmark means Done and should close the keyboard without saving. Repeat on an existing clearly marked fictional recipe's Edit form, without pressing Save.

Try reminder choices on a fictional grocery, chore or planned meal. Back on an untouched form closes directly. Back or Refresh after local changes should offer Keep editing and explicit Discard. The Days before minus/plus buttons should be easy to hit. Do not save reminders merely to test presentation; push delivery remains disabled.

Report the phone, iOS/build, text size and any clipped controls or confusing behavior. Both partners should run the pass independently. Continue the [full phone checklist](swiftui-phone-acceptance.md) afterward. Live AI, scheduled posting/reminders, push, production cutover and full M1–M9 acceptance remain separate and incomplete.
